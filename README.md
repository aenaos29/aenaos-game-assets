# Aenaos Game Assets v0.01

Reusable 3D models, textures and game assets for Aenaos projects. Vesper Courtyard is the first integration target.

The asset directories are `characters/`, `buildings/`, `furniture/`, `vegetation/`, `objects/`, `textures/` and `audio/`. Integration materials live in `tests/`. The manifest records the model URL once verified and the notices record each asset's license.
