# Game Rules

This directory contains the locked mathematical layer for **EMMA vs AENAOS — The Quantisation Trial**.

The authoritative documents are:

- [mathematical-model-v1.md](mathematical-model-v1.md) — human-readable specification.
- [model-config-v1.json](model-config-v1.json) — machine-readable constants and invariants.

These files describe the S01 randomisation layer. They do not replace the canonical case JSON or the game's existing evidence, inference, settlement, and verdict data.

S01 model version: **1.0.0-locked**.
